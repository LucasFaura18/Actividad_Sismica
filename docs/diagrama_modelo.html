2. Decisión Técnica: Semántica At-Least-Once e Idempotencia

El consumidor confirma el offset en Kafka únicamente tras el COMMIT exitoso en PostgreSQL.

sequenceDiagram autonumber participant K as Apache Kafka participant C as Consumidor (Python) participant PG as PostgreSQL (Transacción) K->>C: Mensaje con evento (id, updated_ms) C->>PG: BEGIN TRANSACTION C->>PG: SELECT updated_ms FROM eventos_actuales WHERE id = $id alt Es nuevo C->>PG: INSERT INTO eventos_actuales + eventos_versiones else updated_ms > actual C->>PG: UPDATE eventos_actuales + INSERT eventos_versiones else updated_ms <= actual (duplicado o regresión) C->>PG: DO NOTHING (ignorar cambios) end C->>PG: COMMIT C->>K: commit_offset(partition, offset)
